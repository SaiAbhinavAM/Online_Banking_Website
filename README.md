💳 MERN Banking Website

A full-stack banking web application built with the MERN stack (MongoDB Compass, Express.js, React.js, Node.js) 
that allows users to register, log in, view their account balance, transfer funds, and manage transactions securely.

## 🚀 Features

- ✅ User authentication (signup/login)
- 💰 View account balance and transaction history
- 🔁 Transfer money to other users
- 🧾 Track incoming and outgoing transactions
- 🛠️ MongoDB for storing user and transaction data
- 📦 REST API built with Node.js and Express.js
- 🌐 Responsive React frontend
- 🌐 CORS enabled for secure frontend-backend communication

#Prerequisites:

- Node.js (v14+)
- MongoDB Compass

# Installation:
1) Install backend dependencies:

  cd Online-Banking-Website
- npm install
- npm install react react-dom react-router-dom axios web-vitals react-scripts
- npm install express mongoose cors body-parser --save

2) Banckend Files(server)
a)app.js
b)mongo.js

3) Run the Application

a)nodemon app.js(backend)
b)npm start (frontend)

4) Open http://localhost:3000 in browser

5) In mongo.js file, use appropriate connection string
